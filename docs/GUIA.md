
# Mi Pagina Web Quien soy

Bienvenido a mi proyecto de documentación utilizando Markdown. Para ejecutar algunos comandos desde la terminal puedes utilizar `git status` para verificar el estado del repositorio.

## Características del proyecto

- Uso de Markdown para documentación.
- Organización de archivos en carpetas.
- Control de versiones con Git.
- Publicación en GitHub.

## Pasos de instalación

1. Clonar el repositorio.
2. Ingresar a la carpeta del proyecto.
3. Revisar la documentación disponible.
4. Ejecutar los comandos necesarios.

### Comandos básicos

```bash
git clone https://github.com/ericDeveloper-Tecsup/lab01.git
cd Mi pagina web
git status
```
